# Sales and Profits Dashboard – Power BI

## Project Overview
This project is a Sales and Profits Dashboard created using Power BI.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Features
- Total Sales
- Total Profit
- Sales by Product
- Sales by Category
- Sales Trends
- Interactive Filters
